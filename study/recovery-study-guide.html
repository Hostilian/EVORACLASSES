Study support · five courses

Build a recovery study plan

Map the course, learn the essentials, practise independently and leave time to ask questions. Use the current Moodle materials for the official scope and deadlines.

Start with one useful session

  1. Choose the closest applicable assignment and write its requirements as a checklist.
  2. Attempt one small part yourself for 25 minutes; take a short break.
  3. Check the result against the course material, record one error or question and decide the next step.

A plan or checked box is not proof of mastery or submission. Verify the actual receipt and mark only work you have done.

Map the topics

Use this as a starting map, not a complete or confirmed exam syllabus. Add new topics as they appear in course material and ask the lecturer about the final scope.

  • Web Technologies: HTML structure, semantic elements and forms; CSS cascade, box model, layout and responsive design; browser/network inspection; the current project brief and later taught topics.
  • Software Methods: software processes, stakeholders, requirements and constraints; use cases, class, activity and sequence diagrams; traceability and the project specification.
  • Probability and Statistics: probability and conditional probability; random variables and distributions; joint and conditional models; expectation, variance, moments and common distributions. Check taught material for estimation and inference.
  • Data Transformation and Analysis: Python types, collections and control flow; pandas inspection and transformation; provenance, data quality, missing values, duplicates and outliers. Check current material for later topics.
  • Human–Computer Interaction: interaction models, usability, user research and personas; information architecture, prototyping, heuristic evaluation and usability testing.

For every topic record the source, first attempt, result, correction, question and next review. A successful independent attempt followed by later recall is stronger evidence than time spent reading.

Five weeks before an exam

Time remainingFocus
5 weeksList examinable topics, diagnose gaps and rebuild prerequisites.
4 weeksLearn concepts with worked examples, then solve problems without notes.
3 weeksFinish a first pass, collect questions and ask the teaching team.
2 weeksUse mixed and timed exercises; repair recurring errors.
1 weekPractise under confirmed rules, review errors and check logistics.

Start earlier when the syllabus is large. If less than five weeks remain, begin immediately and prioritize the assessed topics and nearest obligations. Confirm the date, route, format and permitted materials through the course.

Build a realistic week

Allocate time across all courses, projects, recall, explanations and breaks; use actual free time and adjust around classes and work. Near deadlines, temporarily give more time to the closest required project. Record unanswered questions while there is still time to ask.
