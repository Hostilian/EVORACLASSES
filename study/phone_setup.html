One-time connection

Connect your checklist and reminders

Keep this guide open while using GitHub’s private settings. Never put a key in chat, a checklist note or a repository file.

University actions are separate: open your action guide. Finish urgent university steps before account setup.

1. Keep Actions within free usage

Open GitHub billing and review included Actions usage. Under Budgets and alerts, verify an Actions product budget covering the account or private reminder repository is $0 with Stop usage when budget limit is reached enabled. An alert alone does not block charges. Do not increase a budget or add a payment method for this setup.

A verified absence of a valid payment method also blocks use after the included allowance is exhausted. See GitHub’s budget instructions. The website cannot verify billing settings.

2. Create a limited website key

Open the prefilled GitHub key form.

  1. Resource owner: Hostilian.
  2. Choose a short expiration, for example 30 days. Renew it after expiry.
  3. Repository access: Only select repositories.
  4. Select EVORA-STUDY-PROGRESS only.
  5. Repository permissions: Contents → Read and write. GitHub adds Metadata read access automatically. Add no other permissions or repositories.
  6. Select Generate token. GitHub shows its value once. Keep a copy in a password manager or another private location.

3. Save the key for cloud reminders

Open the private reminder repository’s Actions secrets. Select New repository secret.

  1. Name: GH_PROGRESS_TOKEN.
  2. Secret: the limited key from step 2.
  3. Select Add secret.

This is an encrypted setting in the code repository. The key still has access only to the progress repository. A Telegram bot key, if configured, belongs in the separate TG_BOT_TOKEN secret, never in this website.

4. Connect the website on your phone

  1. Open Connect private phone sync.
  2. Paste the limited key into the Private sync token password field.
  3. Select Connect and read private progress.
  4. Tick a task you actually completed, or select Not done yet for an unfinished priority. Wait for Private read and write verified.
  5. Open the same date on another authenticated device and check that the same report appears, if possible.

Do not tick completed just to test syncing. Without a cloud-saved confirmation, reports stay local. The key stays in the open page’s memory; reopening or reloading requires entering it again. Ticks do not prove official registration, submission, attendance or mastery.

5. Keep the Telegram key private

After starting a connected bot, creating another bot is unnecessary. If its key was exposed in chat or elsewhere, open BotFather, use /revoke, select that bot and obtain its replacement key. Edit TG_BOT_TOKEN in the private Actions secrets page and save the replacement there. Do not paste it in chat or in the website. Delivery must be checked with the current key.

6. Finish verification

Tell your assistant which steps are complete, without sending either key: “Key saved, website connected, Actions $0 stop limit confirmed, Telegram key replaced.” Report only what you have actually checked.

The next checks are the real saved phone report, reminder preview and actual delivery. Scheduled notifications stay off until these prerequisites are verified. Proposed cloud times are approximately 08:15 and 21:15 Europe/London; GitHub can delay or drop scheduled runs. Local Codex reviews require the laptop and app to be running.

Study suggestions include Anki, matched videos, practice and breaks within a seven-hour base and eight-hour weekly maximum. Missing reports remain unknown. At most one explicitly unfinished priority replaces lower-priority practice the next day. Official deadlines, Calendar, Moodle and Anki scheduling are not changed by website ticks.
