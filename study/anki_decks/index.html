Import in the Anki app

  1. Choose File → Import, select the downloaded .txt file and choose its destination deck.
  2. Use the Basic note type. In the preview, check Tab as the separator, column 1 = Front, column 2 = Back, column 3 = Tags, and Allow HTML in fields.
  3. Confirm that the preview contains the expected card count before importing. The files contain actual tabs, three import directives and one physical line per note.

If you imported the earlier generic exports, check and back up your existing notes before importing this replacement. Changed question labels can otherwise create duplicates. Choose one set of imports rather than adding both the old and replacement exports.

Text formatting and card counts were checked; a live Anki import has not been independently performed. Browser “Got it” and “Needs practice” marks do not transfer to Anki or change its due-card schedule.

Use them with the study helpers

Review due cards in Anki first. Learn the needed foundation, attempt the related practice before revealing an answer, then use one matched explanation and a fresh attempt in the cards-and-videos routine. Complete the actual Moodle exercises and required projects.
