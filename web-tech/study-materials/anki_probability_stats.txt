What is a sample space Ω? What is an event A?	<b>Sample space (Ω)</b> = set of ALL possible outcomes.<br>Example: rolling a die → Ω = {1,2,3,4,5,6}<br><b>Event (A)</b> = a subset of Ω.<br>Example: A = rolling even = {2,4,6}	STAT_probability
What is the range of any probability P(A)?	<b>0 ≤ P(A) ≤ 1</b><br>P(A)=0 → impossible · P(A)=1 → certain · P(Ω)=1 always	STAT_probability
Write the complement rule.	<b>P(A') = 1 − P(A)</b><br>Example: P(not 6) = 1 − 1/6 = 5/6	STAT_probability
Write the addition rule for P(A∪B).	<b>P(A∪B) = P(A) + P(B) − P(A∩B)</b><br>Mutually exclusive (can't both happen): P(A∩B)=0 → P(A∪B) = P(A) + P(B)	STAT_probability
Write the formula for conditional probability.	<b>P(A|B) = P(A∩B) / P(B)</b><br>"Probability of A given B has occurred." Requires P(B) > 0.	STAT_probability
What does it mean for A and B to be independent?	<b>P(A∩B) = P(A) · P(B)</b><br>Knowing B happened tells you nothing about A.<br>Also: P(A|B) = P(A) if independent.	STAT_probability
State Bayes' Theorem.	<b>P(A|B) = P(B|A) · P(A) / P(B)</b><br>Reverses conditional probability — find P(A|B) from P(B|A).<br>Use: medical tests, spam filters, ML.	STAT_probability
Difference between discrete and continuous random variable?	<b>Discrete</b> = countable values (integers, counts). Example: number of goals scored.<br><b>Continuous</b> = any value in a range. Example: height, temperature, time.	STAT_distributions
What is the Binomial distribution?	Models <b>number of successes in n independent trials</b>, each with probability p.<br>X ~ B(n, p)<br><b>E(X) = np</b><br><b>Var(X) = np(1−p)</b>	STAT_distributions
What is the Normal distribution?	Bell-shaped continuous distribution.<br>X ~ N(μ, σ²)<br>μ = mean, σ = standard deviation<br>Symmetric about mean. Mean = Median = Mode.	STAT_distributions
State the 68-95-99.7 rule for Normal distribution.	<b>68%</b> of data within 1σ of mean<br><b>95%</b> within 2σ<br><b>99.7%</b> within 3σ	STAT_distributions
What is a Z-score? Write the formula.	<b>Z = (X − μ) / σ</b><br>Measures how many <b>standard deviations</b> X is from the mean.<br>Z=0 → at mean. Negative Z → below mean.	STAT_distributions
What is the Poisson distribution used for?	Models <b>number of events in a fixed interval</b> when events happen at a known average rate λ.<br>X ~ Poisson(λ)<br>E(X) = λ · Var(X) = λ	STAT_distributions
What is the Central Limit Theorem?	As sample size n → ∞, the <b>distribution of sample means</b> approaches Normal, regardless of original distribution.<br>Usually requires n ≥ 30.	STAT_distributions
What is H₀ vs H₁?	<b>H₀ (null hypothesis)</b> = "no effect / no difference" — assumed true until disproven.<br><b>H₁ (alternative)</b> = what you want to prove (there IS a difference).	STAT_hypothesis
What is a p-value?	Probability of getting results <b>at least as extreme</b> as observed, IF H₀ is true.<br>p < α → reject H₀ → statistically significant.<br>Common α = 0.05 or 0.01	STAT_hypothesis
What is a Type I error?	<b>False positive</b> — reject H₀ when it IS true.<br>Probability = α (significance level).	STAT_hypothesis
What is a Type II error?	<b>False negative</b> — fail to reject H₀ when it IS false.<br>Probability = β.	STAT_hypothesis
What is the difference between mean, median, and mode?	<b>Mean</b> = sum ÷ count (average — sensitive to outliers)<br><b>Median</b> = middle value when sorted (resistant to outliers)<br><b>Mode</b> = most frequent value	STAT_descriptive
What does standard deviation measure? Write the formula.	Measures average <b>spread</b> around the mean.<br>σ = √[Σ(x−μ)² / n]<br>Small σ = data close together. Large σ = spread out.	STAT_descriptive
What is variance? How is it related to standard deviation?	<b>Var(X) = σ²</b> = [Σ(x−μ)² / n]<br>Variance = square of standard deviation.<br>σ = √Var(X)	STAT_descriptive
What is the IQR?	<b>Interquartile Range</b> = Q3 − Q1<br>Q1 = 25th percentile, Q3 = 75th percentile.<br>Measures spread of middle 50%. Resistant to outliers.	STAT_descriptive
What is Pearson correlation r?	Measures strength of <b>linear relationship</b> between two variables.<br>Range: −1 to +1<br>r=+1 perfect positive · r=−1 perfect negative · r=0 no linear relationship	STAT_descriptive
What is linear regression?	Fits a line: <b>y = β₀ + β₁x</b><br>β₁ = slope, β₀ = intercept.<br>Least squares minimises sum of squared errors.	STAT_descriptive
TRUE/FALSE: Correlation implies causation.	<b>FALSE.</b> Correlation only shows association. There may be a confounding variable. Example: ice cream sales correlate with drowning — both caused by hot weather.	STAT_probability
What is a confidence interval?	A range that likely contains the <b>true population parameter</b>.<br>95% CI means: if we repeated the study 100 times, ~95 of the intervals would contain the true value.	STAT_hypothesis
FORMULA: Expected value of discrete X?	<b>E(X) = Σ [x · P(X=x)]</b><br>Weighted average of all possible outcomes.	STAT_formulas
FORMULA: Var(X) using E(X²)?	<b>Var(X) = E(X²) − [E(X)]²</b>	STAT_formulas
