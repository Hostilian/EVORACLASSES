What is a <b>Sequence diagram</b>? When do you use it?	Shows <b>time-ordered interactions</b> between objects/components.<br>Elements: lifelines (vertical dashed lines), messages (horizontal arrows), activation boxes.<br>Use for: modelling a specific use case, API calls, method interactions.	SW_uml

What is the <b>MVC design pattern</b>?	<b>Model-View-Controller</b> — separates concerns:<br><b>Model</b> — data and business logic<br><b>View</b> — UI/presentation<br><b>Controller</b> — handles user input, coordinates Model and View	SW_patterns

What is a <b>sample space</b> and an <b>event</b> in probability?	<b>Sample space (Ω):</b> set of ALL possible outcomes.<br>Example: flipping a coin → Ω = {H, T}<br><b>Event (A):</b> a subset of the sample space.<br>Example: A = getting Heads = {H}	STAT_probability
What is the range of any probability P(A)?	<b>0 ≤ P(A) ≤ 1</b><br>P(A)=0 → impossible event<br>P(A)=1 → certain event<br>P(Ω)=1 → sample space is always certain	STAT_probability
Write the <b>addition rule</b> for probability.	<b>P(A∪B) = P(A) + P(B) − P(A∩B)</b><br>For mutually exclusive events: P(A∩B)=0, so P(A∪B) = P(A) + P(B)	STAT_probability
Write the <b>complement rule</b>.	<b>P(A') = 1 − P(A)</b><br>P(not A) = 1 minus P(A)<br>Example: P(not rolling a 6) = 1 - 1/6 = 5/6	STAT_probability
Write the formula for <b>conditional probability</b>.	<b>P(A|B) = P(A∩B) / P(B)</b><br>"Probability of A GIVEN B has occurred"<br>Requires P(B) > 0	STAT_probability
What does it mean for two events to be <b>independent</b>?	A and B are independent if: <b>P(A∩B) = P(A) · P(B)</b><br>Knowing B happened gives NO information about A.<br>Also: P(A|B) = P(A) if independent.	STAT_probability
State <b>Bayes' Theorem</b>.	<b>P(A|B) = P(B|A) · P(A) / P(B)</b><br>Lets you "reverse" conditional probability — find P(A|B) from P(B|A).<br>Useful for: medical tests, spam filters, ML classifiers.	STAT_probability
What is the difference between a <b>discrete</b> and <b>continuous</b> random variable?	<b>Discrete:</b> countable values — integers, counts.<br>Example: number of heads in 10 flips = 0,1,2,...,10<br><b>Continuous:</b> any value in a range.<br>Example: height, temperature, time	STAT_distributions
What is the <b>Binomial distribution</b>? Write its parameters.	Models number of <b>successes in n independent trials</b>, each with probability p.<br>Notation: X ~ B(n, p)<br>E(X) = np, Var(X) = np(1−p)<br>Example: number of heads in 10 coin flips ~ B(10, 0.5)	STAT_distributions
What is the <b>Normal distribution</b>? What are its parameters?	Bell-shaped continuous distribution.<br>Notation: X ~ N(μ, σ²)<br>μ = mean (centre), σ = standard deviation (spread)<br><b>68-95-99.7 rule:</b> 68% within 1σ, 95% within 2σ, 99.7% within 3σ	STAT_distributions
What is a <b>Z-score</b>? Write the formula.	Z = (X − μ) / σ<br>Measures how many <b>standard deviations</b> X is from the mean.<br>Z=0 → at mean. Z=2 → 2 SDs above mean.<br>Used to find probabilities from standard normal table.	STAT_distributions
What is the <b>Central Limit Theorem</b>?	As sample size n → ∞, the <b>distribution of sample means</b> approaches a <b>Normal distribution</b>, regardless of the original population distribution.<br>Requires n ≥ 30 typically.	STAT_distributions
What is a <b>null hypothesis</b> H₀ vs <b>alternative hypothesis</b> H₁?	<b>H₀ (null):</b> "no effect", "no difference", status quo. Assumed true until evidence against it.<br><b>H₁ (alternative):</b> what you want to prove — there IS a difference/effect.	STAT_hypothesis
What is a <b>p-value</b>?	Probability of getting results <b>at least as extreme</b> as observed, IF H₀ is true.<br>Small p-value (p < α) → reject H₀ → result is statistically significant.<br>Common α levels: 0.05, 0.01	STAT_hypothesis
What is a <b>Type I error</b> and a <b>Type II error</b>?	<b>Type I (α):</b> Reject H₀ when it IS true. <b>False positive</b>. Probability = α (significance level).<br><b>Type II (β):</b> Fail to reject H₀ when it IS false. <b>False negative</b>. Probability = β.	STAT_hypothesis
What is the <b>mean</b>, <b>median</b>, and <b>mode</b>?	<b>Mean:</b> sum ÷ count (average)<br><b>Median:</b> middle value when sorted (resistant to outliers)<br><b>Mode:</b> most frequent value (can have multiple)<br>For symmetric data: mean ≈ median ≈ mode	STAT_descriptive
What is <b>standard deviation</b>? What does it measure?	σ = √Var(X) = √[Σ(x−μ)²/n]<br>Measures the <b>average spread</b> of data around the mean.<br>Small σ → data clustered near mean. Large σ → data spread out.	STAT_descriptive
What is the <b>IQR</b>? How is it calculated?	<b>Interquartile Range</b> = Q3 − Q1<br>Q1 = 25th percentile, Q3 = 75th percentile.<br>IQR measures spread of the <b>middle 50%</b> of data. Resistant to outliers.	STAT_descriptive
What is <b>Pearson correlation</b> r? What does it measure?	Measures <b>linear relationship</b> between two variables.<br>Range: −1 to +1<br>r=+1: perfect positive linear<br>r=−1: perfect negative linear<br>r=0: no linear relationship	STAT_descriptive
What is <b>ETL</b>? Name the 3 steps.	<b>Extract, Transform, Load</b><br><b>Extract</b> — get data from sources (databases, APIs, files)<br><b>Transform</b> — clean, reshape, aggregate, standardise<br><b>Load</b> — write to destination (data warehouse, database)	DATA_etl
What is the difference between <b>structured</b>, <b>semi-structured</b>, and <b>unstructured</b> data?	<b>Structured:</b> tables with defined schema (SQL databases, CSV)<br><b>Semi-structured:</b> has some organisation but not strict schema (JSON, XML, HTML)<br><b>Unstructured:</b> no predefined format (text, images, video, audio)	DATA_types

What do these SQL aggregation functions do: COUNT, SUM, AVG, MAX, MIN?	<code>COUNT(*)</code> — number of rows<br><code>SUM(col)</code> — total of numeric column<br><code>AVG(col)</code> — average of numeric column<br><code>MAX(col)</code> — highest value<br><code>MIN(col)</code> — lowest value	DATA_sql
What is <b>data normalisation</b> vs <b>standardisation</b>?	<b>Normalisation:</b> scale to [0, 1]. Formula: (x − min) / (max − min)<br><b>Standardisation (Z-score):</b> scale to mean=0, SD=1. Formula: (x − μ) / σ<br>Use standardisation when algorithm assumes normal distribution.	DATA_cleaning

What is <b>HCI</b>? What does it stand for?	<b>Human-Computer Interaction</b> — the study of how people <b>design, evaluate, and implement</b> interactive computing systems for human use.	HCI_definition
What are Nielsen's <b>5 usability components</b>?	1. <b>Learnability</b> — how easy to learn first time<br>2. <b>Efficiency</b> — how fast to use once learned<br>3. <b>Memorability</b> — how easy to recall after a break<br>4. <b>Errors</b> — low error rate, easy to recover<br>5. <b>Satisfaction</b> — pleasant to use	HCI_usability
What is Nielsen's Heuristic #1: <b>Visibility of system status</b>?	System should always <b>keep users informed</b> about what is happening through appropriate feedback within reasonable time.<br>Example: progress bar, loading spinner, "Sending..." message.	HCI_heuristics
What is Nielsen's Heuristic #3: <b>User control and freedom</b>?	Users often choose functions by mistake and need a clearly marked <b>"emergency exit"</b> — support undo and redo.<br>Example: Ctrl+Z, Cancel button, Back button.	HCI_heuristics
What is Nielsen's Heuristic #4: <b>Consistency and standards</b>?	Users should not have to wonder whether different words, situations, or actions mean the same thing. <b>Follow platform conventions</b>.<br>Example: "Save" always means save, not "Export" sometimes and "Save" other times.	HCI_heuristics
What is Nielsen's Heuristic #5: <b>Error prevention</b>?	Design carefully to <b>prevent problems from occurring</b> in the first place. Better than good error messages.<br>Example: confirm before deleting, disable buttons that aren't applicable, inline form validation.	HCI_heuristics
What is Nielsen's Heuristic #6: <b>Recognition rather than recall</b>?	Minimise user's memory load. Make objects, actions, and options <b>visible</b>. Don't make users remember from one page to next.<br>Example: showing recently used files, visible navigation menus.	HCI_heuristics
What is Nielsen's Heuristic #8: <b>Aesthetic and minimalist design</b>?	Dialogues should not contain irrelevant or rarely needed information. <b>Every extra unit of information competes with relevant information</b>.<br>Example: avoid cluttered UIs, remove non-essential decorations.	HCI_heuristics
What is Nielsen's Heuristic #9: <b>Help users recognise, diagnose, and recover from errors</b>?	Error messages should be expressed in <b>plain language</b> (no codes), precisely indicate the problem, and constructively suggest a solution.<br>Example: "Password must be at least 8 characters" not "Error 403".	HCI_heuristics
What is Nielsen's Heuristic #10: <b>Help and documentation</b>?	Even though it is better if system can be used without docs, it may be necessary to provide help. Help should be <b>easy to search, focused on user's task, concrete steps</b>.<br>Example: contextual help tooltips, searchable FAQ.	HCI_heuristics
What are Norman's 6 Design Principles?	1. <b>Affordance</b> — perceived properties suggesting use<br>2. <b>Visibility</b> — controls visible and discoverable<br>3. <b>Feedback</b> — clear signal of action taken<br>4. <b>Mapping</b> — logical relationship between control and effect<br>5. <b>Constraints</b> — limit possible actions<br>6. <b>Consistency</b> — similar operations, similar elements	HCI_norman
What is <b>affordance</b>? Give an example.	Perceived properties of an object that suggest how it should be used.<br>Examples: door handle <b>affords pulling</b>, button <b>affords clicking</b>, slider <b>affords dragging</b>.<br>Poor affordance: flat button that looks like text — users don't click it.	HCI_norman
What is <b>Fitts' Law</b>?	The time to move to a target depends on the <b>distance to the target</b> and <b>size of the target</b>.<br>Larger + closer = faster to hit.<br>Implication: make important buttons <b>big and close</b> to where users are.	HCI_laws
What is <b>Hick's Law</b>?	Decision time increases <b>logarithmically</b> with the number of choices.<br>Fewer options → faster decisions.<br>Implication: don't overwhelm users with too many menu items.	HCI_laws
What are the Gestalt principles relevant to UI design? What is a <b>persona</b> in UX design?	A fictional user archetype based on research, representing a real user group.<br>Includes: name, photo, goals, frustrations, tech comfort level, demographics.<br>Used to keep design focused on real user needs.	HCI_design

What is <b>think-aloud testing</b>?	Usability test where user <b>speaks their thoughts aloud</b> while completing tasks. Reveals what users are confused about, what they expect, and mental models.<br>Cheap and effective — even 5 users reveal 80% of problems.	HCI_testing
