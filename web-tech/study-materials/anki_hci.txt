What is HCI?	<b>Human-Computer Interaction</b> — the study of how people design, evaluate, and implement interactive computing systems for human use.	HCI_definition
Nielsen's 5 usability components?	1. <b>Learnability</b> — easy to learn first time<br>2. <b>Efficiency</b> — fast to use once learned<br>3. <b>Memorability</b> — easy to recall after a break<br>4. <b>Errors</b> — low error rate, easy recovery<br>5. <b>Satisfaction</b> — pleasant to use	HCI_usability
Heuristic #1: Visibility of system status	System must always <b>keep users informed</b> about what is happening through appropriate, timely feedback.<br>Examples: progress bar, loading spinner, "3 of 10 files uploaded"	HCI_heuristics
Heuristic #2: Match between system and real world	System should use <b>users' language</b> — words, phrases, concepts familiar to the user, not system-oriented jargon.<br>Example: "Trash" not "Null pointer reference"	HCI_heuristics
Heuristic #3: User control and freedom	Users make mistakes — need clearly marked <b>emergency exits</b>. Support <b>undo and redo</b>.<br>Examples: Ctrl+Z, Cancel button, Back button.	HCI_heuristics
Heuristic #4: Consistency and standards	Users shouldn't wonder if different words/actions mean the same thing. <b>Follow platform conventions</b>.<br>Example: "Save" always means save everywhere.	HCI_heuristics
Heuristic #5: Error prevention	Design carefully to <b>prevent problems</b> from occurring. Better than good error messages.<br>Examples: confirm before delete, disable inapplicable buttons, inline form validation.	HCI_heuristics
Heuristic #6: Recognition rather than recall	Minimise memory load. Make options <b>visible</b>. Don't force users to remember from one page to next.<br>Examples: visible nav menus, recently used files.	HCI_heuristics
Heuristic #7: Flexibility and efficiency of use	Accelerators (shortcuts) help expert users. Allow users to <b>tailor frequent actions</b>.<br>Examples: keyboard shortcuts, macros, autocomplete.	HCI_heuristics
Heuristic #8: Aesthetic and minimalist design	Every extra unit of information <b>competes with relevant information</b>. Remove non-essential content.<br>Example: clean interfaces with no visual clutter.	HCI_heuristics
Heuristic #9: Help users recognise, diagnose, and recover from errors	Error messages should be in <b>plain language</b>, identify the problem precisely, and suggest a solution.<br>Example: "Password must be 8+ characters" not "Error 403".	HCI_heuristics
Heuristic #10: Help and documentation	Even good systems may need docs. Help should be <b>easy to search, task-focused, concrete steps</b>.<br>Examples: tooltips, searchable FAQ, contextual help.	HCI_heuristics
Norman's 6 design principles?	1. <b>Affordance</b><br>2. <b>Visibility</b><br>3. <b>Feedback</b><br>4. <b>Mapping</b><br>5. <b>Constraints</b><br>6. <b>Consistency</b>	HCI_norman
What is affordance? Example?	Perceived properties of an object that <b>suggest how to use it</b>.<br>✅ Door handle affords pulling. Button affords clicking.<br>❌ Poor affordance: flat text that is actually a clickable link.	HCI_norman
What is mapping in Norman's principles? Example?	Logical relationship between <b>control and its effect</b>.<br>✅ Stove controls positioned to match burner positions.<br>❌ Bad mapping: light switches in the wrong room.	HCI_norman
What is feedback in Norman's principles? Example?	System tells user that <b>an action was performed and its result</b>.<br>Examples: button click sound, confirmation message, progress bar.	HCI_norman
What is constraint in Norman's principles? Example?	<b>Limiting possible actions</b> to prevent errors.<br>Examples: greyed-out disabled buttons, form validation, requiring fields before submit.	HCI_norman
What is Fitts' Law?	Time to move to a target depends on <b>distance</b> and <b>size</b> of target.<br>Bigger + closer = faster to hit.<br>Design implication: make important buttons <b>large and close</b> to user's focus.	HCI_laws
What is Hick's Law?	Decision time increases <b>logarithmically</b> with number of choices.<br>Fewer options → faster decisions.<br>Design implication: don't overwhelm users with too many menu items.	HCI_laws
Name 4 Gestalt principles relevant to UI.	<b>Proximity</b> — close elements seen as related<br><b>Similarity</b> — elements that look alike grouped together<br><b>Continuity</b> — eye follows smooth lines<br><b>Closure</b> — mind completes incomplete shapes	HCI_design
What is a persona in UX?	Fictional user archetype based on research. Includes: name, photo, goals, frustrations, tech comfort.<br>Used to keep design focused on real user needs.	HCI_design
Difference between lo-fi and hi-fi prototyping?	<b>Lo-fi</b> = paper sketches, rough wireframes. Fast, cheap, easy to change. Early in process.<br><b>Hi-fi</b> = interactive digital mockup (Figma). Looks like real product. Used for testing.	HCI_prototyping
What is think-aloud testing?	User <b>speaks thoughts aloud</b> while completing tasks. Reveals confusion, expectations, and mental models.<br>Even 5 users reveal ~80% of usability problems.	HCI_testing
What is A/B testing in UX?	Comparing <b>two versions</b> (A and B) of a design to see which performs better. Usually measured by task completion, error rate, or satisfaction.	HCI_testing
What is a mental model?	User's <b>internal understanding</b> of how the system works — may differ from actual system.<br>Good UX matches the user's mental model.	HCI_design
What is information architecture?	Organising, labelling, and structuring content so users can navigate and find things.<br>Elements: navigation, search, taxonomy, labelling.	HCI_design
What is WCAG? What are the conformance levels?	<b>Web Content Accessibility Guidelines</b><br><b>A</b> — minimum (must have)<br><b>AA</b> — standard (should have, legally required in many countries)<br><b>AAA</b> — enhanced (nice to have)	HCI_accessibility
Minimum colour contrast ratio for normal text (WCAG AA)?	<b>4.5:1</b> for normal text<br><b>3:1</b> for large text (18pt+ or 14pt bold)<br>Use a contrast checker tool — never guess.	HCI_accessibility
TRUE/FALSE: All interactive elements must work with keyboard only for WCAG compliance.	<b>TRUE.</b> Tab key must reach all interactive elements. Users without a mouse depend on keyboard navigation. Failing this fails WCAG Level A.	HCI_accessibility
What is Hierarchical Task Analysis (HTA)?	Breaking a task into a hierarchy of subtasks.<br>Example: "Make a purchase" → Browse → Select → Add to cart → Checkout → Pay	HCI_testing
What is the difference between usability and accessibility?	<b>Usability</b> = how easy and efficient the system is to use for any user.<br><b>Accessibility</b> = whether the system can be used by people with disabilities (visual, motor, cognitive).	HCI_definition
TRAP: Which Nielsen heuristic covers "Undo"?	Heuristic #3: <b>User control and freedom</b>. Not #5 (error prevention) which is about preventing errors before they happen.	HCI_heuristics
TRAP: Affordance vs visibility?	<b>Affordance</b> = the object suggests how to interact with it. <b>Visibility</b> = the user can SEE the controls available. A button with affordance AND visibility is clickable AND visible.	HCI_norman
