# Public study-site agent rules (13 November 2026)

This is a public-facing academic helper. Keep personal progress, identifiers, attendance disputes, raw Moodle originals, credentials, API tokens and other students' information out of this repository and Pages builds.

- Use current cited course sources and explicit dates for all deadlines; this site does not certify present enrollment, attendance, grades, submissions or registrations.
- Examples and practice checklists are not official university statements. Calendar alerts and browser ticks do not prove that work was submitted or accepted.
- Never auto-submit assignments, send emails or post messages as a side effect of building this site. These are separate real-world actions requiring owner approval.
- Preserve published working functionality and tests. Label stale data, fixtures and missing integration clearly instead of inventing healthy states.
- Keep source files/licensing, privacy and accessibility in scope. No private account-routing matrix or professional third-party data belongs here.
- Keep academic evidence and private notification code in their appropriate restricted repositories rather than embedding them into this public site.
